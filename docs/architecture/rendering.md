# Rendering

## Today

- **Backend.** GLFW, Vulkan 1.2 through `ash` with `KHR_dynamic_rendering`, and GLSL compiled to SPIR-V at build time by shaderc ([ADR 0001](../adr/0001-vulkan-renderer.md)). `VulkanBackend` (`crates/photon-render/src/vulkan/backend.rs`) owns two frames in flight, a persistent pipeline cache and self-releasing GPU objects.
- **Pipelines.** About 20 `PipelineKind`s (terrain, translucent, sky, clouds, weather, entity, GUI variants, text, shadows, swirl, ...). `render_types.rs` mirrors the reference's `RenderType` state and is compared in parity runs.
- **Terrain.** 16^3 sections are meshed on a `rayon` pool from a padded region copy, nearest first. Section visibility comes from a `VisGraph` per section, an occlusion flood from the camera section on its own thread, and frustum culling. Each visible section is one `cmd_draw_indexed` with a push constant, from an arena of GPU buffers. The section vertex is 28 bytes.
- **Entities, items and particles.** These are rebuilt on the CPU every frame into per-kind host-visible streams (`DrawKind`).

## Direction

The goal is to cut the work the CPU does per frame without changing what is drawn. The order follows Sodium's lessons; each step is measured with `cargo xtask bench` and must keep parity green.

1. **Region buffers.** Group 8x4x8 sections into one vertex and index buffer each, with sections as sub-ranges allocated inside the region.
2. **Multi-draw indirect.** Issue one indirect draw per region. Commands are written on the CPU first and generated by a compute pass later.
3. **Faces grouped by direction.** Split each section's quads into six facing directions plus unaligned, and skip the directions that face away from the camera.
4. **Compact vertex.** Pack position, UV, colour, light and normal into 16-20 bytes.
5. **Translucency sorting.** Sort only when the camera changes section, and do the sorting on workers.
6. **GPU culling.** Optionally add Hi-Z occlusion for regions and entities on top of the existing flood graph.
7. **Instancing.** Instance entities and particles from persistent GPU buffers instead of re-emitting vertices every frame.
