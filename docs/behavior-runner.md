# Yerel davranış testlerini çalıştırma

Python 3.10+ standart kütüphanesi ve Java 25 JDK kullanılır; yeni Python paketi veya test framework'ü yok. Rust JSONL adaptörü `serde_json` geliştirme bağımlılığını kullanır; üretim kütüphanesi haricî bağımlılık kullanmaz. Java adaptörleri doğrudan sabitlenen Minecraft JAR'ındaki sınıfları çağırır. Beklenen sonuçlar Rust'tan veya test içinde yeniden yazılmış algoritmalardan üretilmez.

Depo kökünden:

```bash
python3 tools/behavior/run.py preflight
python3 tools/behavior/run.py capture
python3 tools/behavior/run.py verify
python3 tools/behavior/test_runner.py
```

- `preflight`: client ve ilgili JAR hash'lerini, Java/javac sürümünü kontrol eder. Oyun veya test çalıştırmaz.
- `capture`: senaryoları iki ayrı Java sürecinde çalıştırır, çıktıları karşılaştırır ve kararlı referansı kaydeder. Aynı kimlikteki kaydı değiştirmez; mevcut kayıt farklı/bozuksa başarısız olur.
- `verify`: kayıtlı referansı değiştirmeden iki yeni Java çalıştırmasıyla karşılaştırır. Önceden `capture` yapılmış olmalı.
- `compare --adapter /mutlak/yol/program`: aynı girdileri belirtilen executable'a verir ve kayıtlı Java sonucuyla karşılaştırır. Rust wire/timer/math/utf8/binary/NBT adaptörü mevcut; bu komut adaptör verilmediğinde **2** ile çıkar. Derleme ve karşılaştırma komutları [binary dilim belgesindedir](binary-parity.md).
- `test_runner.py`: yalnızca yanlış başarı, bozuk referans ve hatalı süreç davranışlarını denetleyen beş küçük sentetik altyapı testi. Java veya asset gerektirmez.

Tek aile seçmek için `--family wire`, `--family math`, `--family timer`, `--family utf8`, `--family binary` veya `--family nbt` kullanılır; seçenek tekrarlanabilir. Seçilmezse mevcut bütün aileler çalışır. Aile seçimi referans kimliğinin parçasıdır; örneğin `verify --family timer` öncesinde aynı seçimle `capture --family timer` çalıştırılmalıdır. `--runtime /yerel/runtime` alternatif client/`libs` dizinini, `--jdk-home /jdk/koku` Java araçlarını seçer. Bu yollar yalnızca okunur. Gerekli referanslar yoksa indirme yapılmaz.

## Sonuç ve çıkış kodları

| Sonuç | Kod | Anlam |
| --- | ---: | --- |
| `preflight_ready` | 0 | Girdi ön kontrolü geçti; davranış doğrulanmadı |
| `reference_ready`, `rust_status=not_compared` | 0 | Java referansı kararlı/kayıtla eşit; Rust karşılaştırılmadı |
| `parity_passed` | 0 | Yalnızca seçilen senaryolarda verilen adaptör Java çıktısıyla eşleşti |
| `failed` | 1 | Çalıştırma/derleme/format hatası veya davranış farkı |
| `blocked` | 2 | Eksik/yanlış referans, yanlış JDK, eksik capture veya adaptör |

Referans komutunun başarılı olması istemcinin eşitliğini göstermez. Seçili bir ailede adaptörün geçmesi de diğer bölümlerin geçtiği anlamına gelmez. Genel CI'a yerel referans veya capture yüklenmez.

## Dosyalar ve kimlik

İzlenen dosyalar: `tools/behavior/` çalıştırıcı ve özgün girdi üreticisi; `tests/behavior/java/` özgün Java çağrı adaptörleri; `tests/behavior/reference.json` sürüm ve gerekli artifact hash'leri. Runtime için yalnızca seçili ailenin JAR'ları kullanılır; assetler, GPU, sunucu ve decompile kaynak ağacı bu ilk testlerin ön koşulu değildir.

Her koşu `.data/runs/behavior/<komut>-<benzersiz>/` altında input, stdout/stderr, derlenen sınıflar, kimlik ve `report.json` tutar. Rapordaki `reproduce` komutu `invocation_cwd` dizininden yeniden çalıştırılabilir. Her capture `.data/captures/behavior/<kimlik>/` altında `inputs.jsonl`, `outputs.jsonl`, `manifest.json` tutar. Referans kimliği client/dependency hash'leri, Java ve javac sürüm çıktısı, OS/mimari, seçilen aileler, Java adaptör/çalıştırıcı kodu ve senaryo girdilerini kapsar. Girdi veya çıktı dosyasının bozulması hash denetimiyle reddedilir.

Kaynak, senaryo veya ortam değişirse yeni kimlik için açıkça `capture` çalıştırılır; eski kayıtlar korunur. Bu kayıtlar kriptografik imzalı güven zinciri değildir; yerel test girdilerini ve kazara değişiklikleri izler. Değişen baseline'ı otomatik kabul eden bir test koşusu yoktur.

## Adaptör protokolü

Executable, stdin'den UTF-8 JSONL alır; her girdi için aynı sırayla stdout'a tek JSON nesnesi döndürür. stdout'a log yazmaz; loglar stderr'e gider. Süre sınırı 60 saniyedir, hata veya eksik/bozuk çıktı başarı sayılmaz. Süreç shell üzerinden başlatılmaz; çalışma dizini ilgili yerel koşu dizinidir.

Her girdi `schema_version: 1`, `case_id`, `family`, `operation` ve operasyona özgü alanlar içerir. Her çıktı aynı `schema_version`/`case_id` ve bir `result` nesnesi içerir. İsteğe bağlı `diagnostics` nesnesi (örneğin Java exception sınıfı) karşılaştırılmaz; bütün `result` alanları tür ve değer açısından kesin karşılaştırılır. Liste/olay sırası korunur; JSON nesnesindeki alan yazım sırası önemli değildir. Eksik/fazla/tekrarlı/sırası değişmiş kayıt başarısızdır.

`wire` ailesi: `codec` alanı `varint` veya `varlong`; `write` girdisindeki `value` işaretli ondalık **string**, `read` girdisindeki `hex` küçük harfli bayt dizisidir. Yazma sonucunda `outcome`, `size`, `hex`, `decoded`, `consumed`, `remaining_hex`; okuma sonucunda `outcome`, `value` veya `error`, `consumed`, `remaining_hex` bulunur. `buffer_underflow` ve `too_big` Java'dan gözlenen hatanın dil bağımsız kategorileridir; sınıf adı yalnızca tanısal kayıttadır.

Wire corpus'u: 144 senaryo; işaretli min/max, 7 bit sınırları, negatif değerler, kesilmiş/fazla uzun/noncanonical kodlamalar ve kalan baytlar. Her `write` çağrısında orijinal decoder da çağrılır; bağımsız sentetik `read` girdileri ayrıca bulunur. UTF-8 ayrı ailede Java referansı olarak hazır; diğer P03 biçimleri henüz kapsanmıyor.

JSON protokolünü konuşan bir executable'ın programlama dili araç tarafından kanıtlanmaz. `examples/behavior_adapter.rs` mevcut gerçek Rust wire/timer/math adaptörüdür; rapor executable SHA-256'sını ve seçili kapsamı kaydeder. Altyapı denemelerinde kullanılan sentetik programlar oyun eşitlik kanıtı değildir.

## Sayısal ve zamanlayıcı protokolü

`math/vec2`: girdide `x`, `y` ve `steps` bulunur. Float girdiler 8 haneli küçük harfli IEEE-754 hex string'leridir. `steps` içindeki `normalize` vektör normalizasyonunu, `scale` ise aynı kayıttaki `factor` çarpanıyla ölçeklemeyi çağırır. `result.events`, başlangıçta ve her işlemden sonra `x`, `y`, `length`, `length_squared` bitlerini içerir.

`math/vec3`: girdide `x`, `y`, `z` ve `steps` bulunur. Float girdiler 16 haneli küçük harfli IEEE-754 hex string'leridir. `steps` içindeki `normalize` vektör normalizasyonunu, `scale` aynı kayıttaki `factor` çarpanıyla ölçeklemeyi, `reverse` Java Vec3.reverse() çağrısını, `multiply_vec3` ve `multiply_components` Java Vec3 multiply overload'larını, `horizontal` Java Vec3.horizontal() çağrısını, `add_vec3`/`subtract_vec3` `delta` Vec3 değerini, `add_scalar`/`subtract_scalar` `value` değerini, `add_components`/`subtract_components` ise `x`, `y`, `z` miktarlarını Java Vec3 overload'larına verir. `vector_to`, hedef Vec3 değerini `target` nesnesinden alıp Java `vectorTo` çağrısına; `cross`, ikinci Vec3 değerini `other` nesnesinden alıp Java `cross` çağrısına verir. `result.events`, başlangıçta ve her işlemden sonra `x`, `y`, `z`, `length`, `length_squared` bitlerini içerir.

`math/vec3_codec`: `mode: "decode"` için `values` alanındaki raw f64 bit listesi Java `Vec3.CODEC` sabit boyutlu liste yoluna verilir; tam üç öğede Vec3 snapshot'ı, kısa/boş listede hata, uzun listede ilk üç öğeden `partial` snapshot döner. `mode: "encode"` için `x`, `y`, `z` raw f64 bitleri x/y/z sırasındaki üç öğeli listeye çevrilir. JSON sayı türlerinin genel metin ayrıştırması bu operation'ın kapsamı değildir.

`math/vec3_dot`: `first` ve `second` Vec3 nesnelerini alır. Her bileşen 16 haneli f64 bit string'idir; Java `Vec3.dot` sonucu `result.value` içinde 16 haneli f64 bit string olarak taşınır.

`math/vec3_distance_to`: `first` ve `second` Vec3 nesnelerini alır; Java `Vec3.distanceTo(Vec3)` sonucu `result.value` içinde 16 haneli f64 bit string olarak taşınır.

`math/vec3_distance_to_sqr`: `first` ve `second` Vec3 nesnelerini alır; Java `Vec3.distanceToSqr(Vec3)` sonucu `result.value` içinde 16 haneli f64 bit string olarak taşınır. `math/vec3_distance_to_sqr_components` aynı sonucu `first` Vec3'ü ile `x`, `y`, `z` hedef bileşenlerinden üretir.

`math/vec3_horizontal_distances`: `first` Vec3 nesnesini alır; Java `Vec3.horizontalDistance()` ve `Vec3.horizontalDistanceSqr()` sonuçlarını `result.distance` ve `result.distance_squared` içinde 16 haneli f64 bit string olarak taşır.

`math/vec3_closer_than`: `first` ve `second` Vec3 nesnelerini, `distance`, `distance_xz` ve `distance_y` eşiklerini alır; Java `closerThan(Position, double)` sonucu `result.position`, `closerThan(Vec3, double, double)` sonucu `result.xz_y` içinde boolean olarak taşınır.

`math/vec3_offset_random`: `first` Vec3 nesnesini, decimal i64 `seed` değerini ve sekiz haneli f32 bit string'i `offset` değerini alır. Aynı seed iki Java `RandomSource` örneğinde kullanılır; `offset_random` üç çekişli, `offset_random_xz` iki çekişli Vec3 snapshot'ı döndürür.

`math/vec3_lerp`: `first` ve `second` Vec3 nesnelerini ve on altı haneli f64 bit string'i `alpha` değerini alır; Java `Vec3.lerp(Vec3, double)` sonucu `result.value` içinde Vec3 snapshot'ı olarak döndürülür.

`math/vec3_rotate_clockwise_90`: `first` Vec3 nesnesini alır; Java `Vec3.rotateClockwise90()` sonucu `result.value` içinde Vec3 snapshot'ı olarak döndürülür.

`math/vec3_is_finite`: `first` Vec3 nesnesini alır; Java `Vec3.isFinite()` sonucu `result.value` içinde boolean olarak döndürülür.

`math/vec3_get`: `first` Vec3 nesnesini ve `axis` olarak `x`, `y` veya `z` adını alır; Java `Vec3.get(Direction.Axis)` sonucu `result.value` içinde 16 haneli f64 bit string olarak döndürülür.

`math/vec3_with`: `first` Vec3 nesnesini, `axis` olarak `x`, `y` veya `z` adını ve 16 haneli f64 bit string `value` değerini alır; Java `Vec3.with(Direction.Axis, double)` sonucu `result.value` içinde Vec3 snapshot'ı olarak döndürülür.

`math/vec3_relative`: `first` Vec3 nesnesini, `direction` olarak altı yön adından birini ve 16 haneli f64 bit string `distance` değerini alır; Java `Vec3.relative(Direction, double)` sonucu `result.value` içinde Vec3 snapshot'ı olarak döndürülür.

`math/vec3_align`: `first` Vec3 nesnesini ve `axes` olarak `x`, `y`, `z` eksen adlarından oluşan diziyi alır; Java `Vec3.align(EnumSet<Direction.Axis>)` sonucu `result.value` içinde Vec3 snapshot'ı olarak döndürülür.

`math/vec3_projected_on`: `first` ve `onto` Vec3 nesnelerini alır; Java `Vec3.projectedOn(Vec3)` sonucu `result.value` içinde Vec3 snapshot'ı olarak döndürülür.

`math/vec3_to_vector3f`: `first` Vec3 nesnesini alır; Java `Vec3.toVector3f()` sonucu `result.value` içinde f32 `x`, `y`, `z` ham bit snapshot'ı olarak döndürülür.
`math/vec3_coordinates`: decimal string x/y/z BlockPos bileşenlerini ve `kind` alanını alır; Java koordinat yardımcısının Vec3 sonucu `result.value` içinde f64 ham bit snapshot'ı olarak döndürülür.

`math/vec3_equality`: `first` ve `second` Vec3 nesnelerini alır; Java `Vec3.equals` sonucu `result.equals` içinde boolean, iki `hashCode` sonucu `first_hash` ve `second_hash` içinde decimal string olarak taşınır. `Double.compare`, signed zero ve NaN canonicalization davranışı korunur.

`math/vec3_to_string`: `first` Vec3 nesnesini alır; Java `Vec3.toString()` sonucu `result.value` içinde sabit ayraçları ve Java double metin biçimini koruyan string olarak taşınır.
`math/vec3_rotate`: `first` Vec3 nesnesi, `axis` (`x`, `y`, `z`) ve f32 bit dizgeli `radians` alır; Java `xRot`, `yRot` veya `zRot` sonucu `result.value` içinde Vec3 snapshot olarak taşınır.

`math/vec3_direction_from_rotation`: `kind: "components"` için f32 bit dizgeli `rot_x`/`rot_y`, `kind: "vec2"` için f32 bit dizgeli `rotation` Vec2 alır; Java `directionFromRotation` overload sonucu `result.value` içinde Vec3 snapshot olarak taşınır.

`math/vec3_local_coordinates`: `kind: "apply"` için f32 bit dizgeli `rotation` Vec2 ve f64 bit dizgeli `direction` Vec3, `kind: "add"` için f64 bit dizgeli `first` ve `direction` Vec3 alır; Java `applyLocalCoordinatesToRotation` veya `addLocalCoordinates` sonucu `result.value` içinde Vec3 snapshot olarak taşınır.

`math/vec3_rotation`: f64 bit dizgeli `first` Vec3 alır; Java `Vec3.rotation()` sonucu `result.value` içinde f32 `x`, `y`, `length` ve `length_squared` bitleriyle Vec2 snapshot olarak taşınır.

`math/vec2_rotate`: f32 bit dizgeli `first` Vec2 ve f64 bit dizgeli `angle` alır; Java `Vec2.rotate(double)` sonucu `result.value` içinde f32 `x`, `y`, `length` ve `length_squared` bitleriyle Vec2 snapshot olarak taşınır.

`math/vec2_dot`: f32 bit dizgeli `first` ve `second` Vec2 nesnelerini alır; Java `Vec2.dot(Vec2)` sonucu `result.value` içinde 8 haneli f32 bit string olarak taşınır.

`math/vec2_add_vec2`: f32 bit dizgeli `first` ve `second` Vec2 nesnelerini alır; Java `Vec2.add(Vec2)` sonucu `result.value` içinde Vec2 snapshot olarak taşınır.

`math/vec2_add_scalar`: f32 bit dizgeli `first` Vec2 ve `value` scalar'ını alır; Java `Vec2.add(float)` sonucu `result.value` içinde Vec2 snapshot olarak taşınır.

`math/vec2_distance_to_sqr`: f32 bit dizgeli `first` ve `second` Vec2 nesnelerini alır; Java `Vec2.distanceToSqr(Vec2)` sonucu `result.value` içinde 8 haneli f32 bit string olarak taşınır.

`math/vec2_negated`: f32 bit dizgeli `first` Vec2 nesnesini alır; Java `Vec2.negated()` sonucu `result.value` içinde Vec2 snapshot olarak taşınır.

`math/vec2_equality`: f32 bit dizgeli `first` ve `second` Vec2 nesnelerini alır; Java `equals` sonucu `equals`, iki `hashCode` sonucu `first_hash` ve `second_hash` alanlarında decimal string olarak taşınır.

`math/vec2_constant`: `name` olarak `zero`, `one`, `unit_x`, `neg_unit_x`, `unit_y`, `neg_unit_y`, `max` veya `min` alır; Java Vec2 sabiti sonucu `result.value` içinde f32 Vec2 snapshot olarak taşınır.

`math/vec3_constant`: `name` olarak `zero`, `x_axis`, `y_axis` veya `z_axis` alır; Java Vec3 sabiti sonucu `result.value` içinde f64 Vec3 snapshot olarak taşınır.

`math/vec3` içindeki `reverse`, Java `Vec3.reverse()` çağrısını; `multiply_vec3` ve `multiply_components`, Java multiply overload'larını; `horizontal`, Java `Vec3.horizontal()` çağrısını yapar. Her işlemden sonra vektör snapshot'ı üretilir.

Diğer `math` operasyonları `floor`, `wrap_degrees`, `clamp`; `type` alanı `f32` veya `f64`'tür. `value` ve clamp'in `min`/`max` alanları türe göre 8/16 haneli hex bit string'idir. `floor` her iki overload için de i32 sonucu `result.value` ondalık string olarak döndürür; diğerleri `result.bits` üretir. Int/long overload'ları bu dilime dahil değil.

`math/aabb`: `kind` alanı yoktur; başlangıç kutusu ve `steps` içindeki `contains`, `contains_vec3`, `intersects`, `intersects_coords`, `intersects_vec3`, `intersects_block_pos`, `collided_along_vector`, `from_block_pos`, `from_vec3`, `unit_cube_from_lower_corner`, `encapsulating_full_blocks`, `of_bounding_box`, `intersect`, `move`, `move_block_pos`, `move_vec3`, `move_vector3f`, `sizes`, `has_nan`, `positions`, `min`, `max`, `distance_point`, `distance_box`, `of_size`, `set_min_x`, `set_min_y`, `set_min_z`, `set_max_x`, `set_max_y`, `set_max_z`, `clip`, `clip_coords`, `clip_many`, `expand`, `expand_vec3`, `equals`, `hash_code`, `to_string`, `contract`, `inflate`, `inflate_xyz`, `deflate_xyz` veya `deflate` işlemleri Java `AABB` çağrılarına verilir. Delta, merkez ve kutu endpoint'leri f64 bit string'leridir. `contains_vec3` Vec3 konumunu, `intersects_coords` ham f64 endpoint'lerini, `intersects_vec3` iki Vec3 endpoint'ini, `intersects_block_pos` BlockPos konumunu alır. `collided_along_vector` hareket vektörünü ve AABB nesnelerinden oluşan `boxes` listesini alır; hareketli kutunun merkezinden aday kutulara karşı Java collidedAlongVector çağrısını yapar. `from_block_pos` BlockPos konumunu, `from_vec3` iki Vec3 endpoint'ini, `unit_cube_from_lower_corner` alt köşe Vec3'ünü ve `encapsulating_full_blocks` iki BlockPos konumunu alır; `of_bounding_box` ise altı decimal int endpoint'i taşıyan `box` nesnesini `BoundingBox` constructor'ı ve `AABB.of` üreticisine verir. Her biri mevcut kutuyu Java kurucu/üretici sonucu ile değiştirir ve snapshot üretir. `expand_vec3`, Vec3 bileşenlerini Java `AABB.expandTowards(Vec3)` overload'ına verir ve scalar genişletme yoluyla yeni snapshot üretir. `equals`, Java `AABB.equals` endpoint karşılaştırmasını; `hash_code`, Java `AABB.hashCode` sonucunu event olarak taşır. `to_string`, Java `AABB.toString()` metnini `value` alanında taşır. `clip_coords` altı ham f64 endpoint'ini ve `from`/`to` Vec3 konumlarını alır; koordinatları normalize etmeden Java statik clip overload'unu çağırır ve başarılı noktayı snapshot'lar. `clip_many` AABB listesini, `from`/`to` noktalarını ve decimal i32 `pos` BlockPos'unu alır; Java iterable clip overloadunu çağırır ve hit durumunda konum, yüz yönü, tür, BlockPos ve hit bayraklarını snapshot'lar. `move_block_pos` BlockPos koordinatlarını decimal i32 dizgeleriyle, `move_vec3` konumu f64 bit string'leriyle, `move_vector3f` konumu f32 bit string'leriyle alır. `of_size` adımı merkez ile üç eksen boyutunu alır, mevcut kutuyu yeni `AABB.ofSize` sonucu ile değiştirir ve snapshot üretir. `set_min_x`, `set_min_y`, `set_min_z`, `set_max_x`, `set_max_y` ve `set_max_z` adımları ilgili endpoint değerini alır, yeni kutuyu ve snapshot'ı üretir. `sizes` sorgusu `x_size`, `y_size`, `z_size` ve ortalama `size` değerlerini f64 bit string olarak taşır. `positions` sorgusu dört Vec3 snapshot'ını ve her snapshot için x, y, z, length ve length_squared f64 bit string alanlarını taşır. `min` ve `max` sorguları seçilen eksenin endpoint'ini, `distance_point` ve `distance_box` sorguları kareli uzaklığı `value` f64 bit string alanında taşır. `events` başlangıç ve her adım sonrası kutu veya sorgu sonucunu taşır.

`math/aabb_builder`: `points` dizisi f32 bit string bileşenleri taşır. Başlangıçta ve her nokta sonrasında `defined` event’i, `build` alanında ise tanımlı AABB snapshot’ı veya `undefined` hata sonucu döner; Java tarafında `AABB.Builder.include(Vector3fc)`, `isDefined()` ve `build()` çağrılır.

`math/shape`: `kind: "single"` box girdisini ve `steps` içindeki `move`, `move_vec3` ve `move_block_pos` işlemlerini, `kind: "join"` ise iki box'ın `op: "or"`, `"and"`, `"only_first"`, `"only_second"`, `"false"`, `"not_same"`, `"second"` veya `"first"` birleşimini çağırır. `kind: "join_many"` ilk shape ve `shapes` dizisinin kalanını Java varargs OR yoluna verir. `kind: "single_encompassing"` aynı diziden oluşturulan shape üzerinde Java `singleEncompassing()` çağrısını yapar. `kind: "optimize"` shape'i Java `joinUnoptimized(..., OR)` ile kurar, önce ve sonra `optimize()` snapshot'ı ile coordinate plane listesini karşılaştırır. `kind: "edges"` birleşik shape üzerinde Java `forAllEdges` sırasındaki kenar uçlarını f64 bitleriyle döndürür. `kind: "join_coords"` iki box için Java `joinUnoptimized` ve `join` sonuçlarını ayrı ayrı, coordinate plane snapshot'larıyla döndürür. `kind: "boxes"` shape'i Java `forAllBoxes` callback'iyle tarar ve callback uçlarını f64 bitleriyle döndürür; `kind: "create_aabb"` ise AABB girdisini Java `Shapes.create(AABB)` overload'una verir ve shape snapshot'ını döndürür; `kind: "create_coords"` ise ham koordinat endpoint'lerini Java `Shapes.create(double...)` overload'una verir ve shape snapshot'ını döndürür; `kind: "infinity"` ise Java `Shapes.INFINITY` karşılığını snapshot, callback veya self-`NOT_SAME` sorgusuyla taşır; `kind: "constants"` ise `Shapes.EPSILON` ve `Shapes.BIG_EPSILON` değerlerini f64 bitleriyle döndürür. `kind: "axis_limits"` oluşturulan shape'in X/Y/Z min ve max değerlerini Java API'siyle sorgular. `kind: "axis_limits_at"` aynı shape'i axis ve diğer iki koordinat sorgularıyla Java `min/max(axis, b, c)` overload'larına verir. `kind: "collide"` tek shape box'ı, moving AABB'yi, `axis` ve distance girdisini Java `VoxelShape.collide` yoluna verir; `kind: "collide_many"` aynı girdileri `shapes` dizisiyle Java `Shapes.collide` yoluna verir; `kind: "clip"` bir shape, `from`/`to` Vec3 noktaları ve BlockPos içeren `queries` dizisini Java `VoxelShape.clip` yoluna verir; `kind: "clip_join"` iki box'ı OR ile birleştirip aynı sorgu yolunu kullanır; `kind: "closest"` tek shape için, `kind: "closest_join"` OR birleşimi için `point` sorgusunu Java `VoxelShape.closestPointTo` yoluna verir. `kind: "face"` tek shape, `kind: "face_join"` OR birleşimi için `direction` sorgusunu Java `VoxelShape.getFaceShape` yoluna verir; `kind: "block_occludes"` tek shape/occluder, `kind: "block_occludes_join"` OR birleşimi shape/occluder ile Java `Shapes.blockOccludes` yolunu kullanır; `kind: "merged_occludes"` direction ile Java `Shapes.mergedFaceOccludes` yolunu, `kind: "face_occludes"` iki face shape ile Java `Shapes.faceShapeOccludes` yolunu kullanır; `kind: "equal"` iki box girdisini Java `Shapes.equal` yoluna verir ve `equal` boolean sonucu taşır; `kind: "rotate"` bir box ile `rotation` adını Java `Shapes.rotate` yoluna verir; `kind: "rotate_join"` iki box'ı OR ile birleştirip döndürür; `kind: "rotate_center"` bir box ile `rotation` ve `center` alanlarını Java merkez overload'ına verir; `kind: "rotate_horizontal_axis"` Z ekseni shape'inden Java EnumMap sırasındaki X/Z varyantlarını üretir; `kind: "rotate_horizontal_axis_center"` aynı X/Z map'ini `center` alanıyla üretir; `kind: "rotate_all_axis"` north shape'inden Java EnumMap sırasındaki X/Y/Z varyantlarını üretir; `kind: "rotate_all_axis_center"` aynı X/Y/Z map'ini `center` alanıyla üretir; `kind: "rotate_horizontal"` north shape'inden Java EnumMap sırasındaki NORTH/SOUTH/WEST/EAST varyantlarını üretir; `kind: "rotate_all"` north shape'inden Java EnumMap sırasındaki DOWN/UP/NORTH/SOUTH/WEST/EAST varyantlarını üretir; `kind: "rotate_all_center"` north shape'inden `center` alanıyla aynı yön map'ini üretir; `kind: "rotate_all_initial"` north shape'inden `initial` ve `center` alanlarıyla altı yön map'ini üretir; `kind: "rotate_attach_face"` north shape'inden FLOOR, WALL ve CEILING için iç yön map'lerini üretir; `kind: "rotate_attach_face_initial"` desteklenen initial dönüşle aynı attach-face map'ini üretir; `kind: "rotate_horizontal_initial"` desteklenen initial dönüşle dört yatay yön map'ini üretir. Box koordinatları f64 bit string'leridir. Shape snapshot'ı `empty`, Java'nın `toAabbs` sırasındaki `boxes` ve non-empty durumda `bounds` alanlarını taşır; birleşim sonucu ayrıca `join_is_not_empty` içerir.

`timer/trace`: `tps`, `target_mspt` f32 bit string; `start_ms` i64 ondalık string'dir. Sıralı `steps`: `game`/`real` adımları `ms` i64 string; `pause`/`freeze` adımları `value` boolean; `target` adımı `value` f32 bit string alır. Sağlayıcı başlangıçta `target_mspt`, değişiklikten sonra verilen `target` değerini döndürür. Bu, gerçek Timer API'sine kontrollü girdi sağlar.

`result.events`, başlangıçta ve her adımdan sonra `game_delta`, `partial`, `partial_ignore_frozen`, `real_delta` alanlarını f32 bit string olarak taşır. Yalnızca `game` adımının sonucunda ayrıca `ticks` JSON integer vardır. Timer'ın iç alanları refleksiyonla değiştirilmez; yalnızca constructor ve gerçek public API çağrılır. Frame başına 10 tick sınırı bu Timer testine eklenmez.
